# So You Want To Model Materials In Quantum Espresso
Quantum Espresso can be a powerful tool for material modelling - with the right knowledge, of course! 

This is a repository containing the lessons I've learned while working with Quantum Espresso 7.5 to model Tetragonal Barium Titanate.

If you find it useful, PLEASE DON'T FORGET TO CITE!
